# Reglas de Documentación

Aplica a toda la documentación del repositorio (`**/*.md`).

## Principios y Convenciones

- Toda la documentación técnica, funcional y de arquitectura vive en el directorio `template-docs/`.
- Mantener la documentación sincronizada con los cambios de código, nuevos endpoints, modelos y configuraciones.
- Usar formato Markdown estándar, diagramas Mermaid cuando ayuden a clarificar flujos y enlaces relativos válidos.
- Estructura organizada por secciones: `01-introduction`, `02-functional`, `03-technical`, `04-development`.
- Sigue la guía oficial: [template-docs/04-development/coding-guidelines/documentation.md](file:///Users/ijgomez/Documents/workspace/template/template-docs/04-development/coding-guidelines/documentation.md).
