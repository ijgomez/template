# Template

El proyecto consiste en el desarrollo de una **plantilla base para aplicaciones empresariales modernas**, basada en **Spring Boot** y **Angular**, que proporciona desde el inicio todas las funcionalidades transversales habituales de una aplicación corporativa:

- Autenticación y autorización basada en perfiles y acciones.
- Gestión de usuarios y seguridad.
- Administración del sistema, auditoría y supervisión de interfaces.
- Monitorización de entornos en alta disponibilidad (cluster).
- Internacionalización (i18n).
- Soporte offline mediante PWA y diseño responsivo.

Sobre esta base común se incorporan los módulos funcionales propios de cada proyecto, comenzando por un sistema de generación, consulta y exportación de informes.

El objetivo es disponer de una plataforma reutilizable, escalable y mantenible que unifique la arquitectura, el modelo de datos, la experiencia de usuario y las buenas prácticas de desarrollo, reduciendo significativamente el esfuerzo necesario para iniciar nuevos proyectos y garantizando la homogeneidad entre las aplicaciones desarrolladas.
